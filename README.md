# 成人 ADHD 临床评估准备问卷

这是一个纯前端的成人 ADHD 就诊前自评网页。页面依据国际通行的 ADHD 核心诊断框架重新编写，包含 18 个核心症状领域、童年起病、跨场景表现、功能损害与鉴别因素提示。

## 在线访问

- GitHub Pages：https://zxinrain.github.io/-adhd-test/
- 免 Pages 构建直出：https://raw.githack.com/zxinrain/-adhd-test/gh-pages/index.html

所有答题数据仅在浏览器本地处理，不上传服务器。

> 没有任何在线自测能够自行确诊 ADHD。本工具不是官方 ASRS 原文，也不是经过重新验证的量表；正式诊断需要由有经验的专业人员完成临床评估。
